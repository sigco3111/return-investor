# 리턴: 회귀 투자자

2026-11-09 개발 코드 체크포인트입니다. 완성 게임이나 플레이 배포가 아닙니다.

남성 주인공이 고등학교 시점으로 회귀해 공부·아르바이트, 진학 후 취업·전업 투자와 자산 배분을 선택하는 비주얼 노벨형 투자게임 시제품입니다. 개별주식 대신 지수 투자를 다루며, 지난 인생의 주요 기록을 보존하고 다음 회귀에서 비교하는 방향으로 개발 중입니다.

## 포함한 것

- `engine.js`: 현재 시제품의 턴·진로·주문·저장·결산·회귀 대시보드 코드.
- `asset-review.js`: 시작자금·시험 순저축·잔차 분해 및 두 기록 비교.
- `economy-policy.js`: 시험 순저축 모형과 저장 형식의 제한적 검사.
- `index.html`: UI 소스. 공개 등록 구조에서는 네 JS 파일이 루트에 있어 경로만 맞췄습니다.
- `check-asset-review.js`: 자산 분해와 비교의 합성 단위검사30개.
- `tuition-choice-lab.html`: 본게임과 연결하지 않은 독립2회차 선택 실험. 모든 금액은 임의 시험값이며 현실 학비·급여·진로 효과가 아닙니다. 새로고침하면 초기화합니다.

## 실행과 데이터 제외 범위

역사 뉴스·시세·금리 및 제도자료의 원자료 재배포권 검토가 끝나지 않아 `data/` 전체와 관련 연구원문을 공개본에서 제외했습니다. 비공개 제작 이미지도 이번 공개 등록에는 포함하지 않았습니다. 본게임이 읽는 `data/events.json`, `data/prices.json`, `data/turns.json`, `data/unlocks.json`, `data/rates.json`이 없으므로 **이 저장소만 내려받아서는 본게임을 정상 실행할 수 없습니다.** `index.html`은 코드 검토용이며 이미지도 표시되지 않습니다. 데이터가 빠진 상태를 빈 시장이나 실제 역사 데이터로 대체하지 않았습니다.

독립 실험은 `tuition-choice-lab.html`을 브라우저에서 별도로 열어 볼 수 있지만 본게임이 아닙니다. 공개 플레이 사이트나 GitHub Pages는 이번 등록에 포함하지 않습니다.

## 검사

Node.js에서 `npm test`는 공개된 자산복기 합성 단위검사30개만 실행합니다. `npm run check`는 세 JS의 구문을 검사합니다. 별도 개발본의 전체 정상 UI 회귀검사는 역사 데이터가 필요하므로 이 공개본에서는 재현할 수 없습니다. 합성검사 통과를 실제 과거저장 호환성·현실 진로균형·이용자 재미 검증으로 해석하지 않습니다.

## 개발 상태와 남은 일

본게임은 시험 순저축과 시연 금리·지연체결 규칙을 사용합니다. 실제 급여·생활비·학비·세금·거래비용을 연결하지 않았습니다. 자산복기의 잔차는 상품 평가변화·이자·환산 등이 섞인 금액으로 투자수익률이나 실현수익이 아닙니다. 두 인생의 금액 차이는 조건을 통제한 비교가 아닙니다.

진로의 장기 결과와 생활경제 연결, 역사자료 권리·시점 검증, 실제 플레이 시간·재미 및 다양한 브라우저 검증이 남아 있습니다. 투자 조언이나 역사적 거래 재현이 아닙니다.

개인정보·비밀정보·대화기록·내부 작업기록·원자료는 포함하지 않았습니다. 별도 오픈소스 라이선스는 아직 지정하지 않았습니다.

## 진로 선택 전 흐름 비교

진로 카드에서 공부·알바, 진학 시나리오·일반 시작, 대학 졸업 후 취업·전업의 현재 규칙을 열어 비교할 수 있습니다. 읽기 전용 안내이며 월·자산·선택을 바꾸거나 미래자산을 예측하지 않습니다. 시험 순저축, 주문 기회, 재학/복무 일정, 현재 전업 하한과 생활경제 빈칸을 구분합니다. 대학 졸업 전업에는 시험 하한1200만원이 있지만 알바 경로에는 같은 검사가 없는 현재 차이도 표시합니다. 기존 경제·선택 규칙은 그대로입니다.

별도 전체 개발본에서 정상 시작 네 경로의 각각367개월과 지도 열기·닫기·재로드 원문불변을 확인했습니다. 이는 공개본의 `npm test`에 포함되지 않으며, 제외한 역사 데이터 없이 재현할 수 없습니다. 실제 진로균형·생활가능성·재미나 전업 하한 충족 경로의 검증이 아닙니다.

## 별도 현금사건 시험 회귀

본게임 새 시작 화면과 자산표의 링크에서 별도 현금사건 시험 회귀에 들어갈 수 있습니다. 임의 시험가정에 체크한 새 시작에만 적용하며 기존 시험순저축의 진행·회귀기록과 저장키를 분리합니다. 기존모형의 금액을 소급 변경하지 않습니다. 공개본은 여전히 데이터가 없어 이 모드를 정상 실행할 수 없습니다.

이 모형은 기존 월 순저축을 끄고 시작100만원, 고교알바·졸업취업 월수입30만원/그 외·복무0원, 월생활 가상청구10만원(복무 포함), 최초 재학 월진행 학비가상청구80만원 한 번을 명시합니다. 금액은 전부 임의값으로 역사적 급여·학비·생계비가 아닙니다. 실제학교·공제·장학·가족부담·환급·학적정책을 재현하지 않습니다.

월 진행에 수입/청구를 한 번만 만들고, 납부는 사용가능현금으로 전액 확인하거나 미납으로 명시 보류합니다. 자동대출·매도·가족송금은 없으며 예약금은 사용할 수 없습니다. 보류 미납을 나중에 다시 낼 수 있지만 이 최소시험에서 보류는 학적·복무 일정을 바꾸지 않습니다. 총자산은 미납 차감 전이고 미납과 시연순자산을 함께 표시합니다. 수익률·진로우열·재미나 현실 생활가능성의 검증이 아닙니다.

## 저장 반영 실패 보호

진행키와 회귀기록키의 읽기를 별도로 확인하고, 회귀기록은 쓰기 후 원문 재읽기를 확인한 뒤 진행키를 지우며 삭제도 확인합니다. 실패하면 추가 진행과 자동 재시도를 멈추고 사용자가 저장 상태를 다시 불러오게 합니다. 쓰기 뒤 오류는 실제로 반영됐을 수도 있어 이전 상태 보존을 보장하지 않습니다. 완료회귀의 지속 식별자로 재로드 후 기록 재시도 중복을 피합니다.

별도 개발본에서 두 현금사건키의 읽기·쓰기·재읽기·삭제 관련 합성 오류주입14경우와 모형 복귀 원문동일, 명시 재로드 후 중복없는 재기록을 확인했습니다. 이는 정상UI 검사25종과 별도이고 실제 디스크·브라우저권한 실패나 다중탭 원자성을 검증한 것은 아닙니다. 역사 데이터가 제외되어 이 저장소에서는 전체 UI 검사를 재현할 수 없습니다.

## 주요선택 연표와 현금 진로지도

새로 확정한 주요행동은 월진행 전 게임 월을 별도 기록하며 완료 회귀의 대시보드에서 진로·복무·매매 흐름과 가상청구 내역을 펼쳐 읽습니다. 매수신청과 체결, 자동 전역일정 확인과 입대 선택을 구분합니다. 과거 기록이나 선택월 근거가 없는 행동은 추정해 채우지 않습니다. 기기 내 저장이며 클라우드 동기화나 계정 영구보존이 아닙니다.

현금모형의 시작이력·고1·대학졸업 선택에는 실제 현재 미납·차감순자산·사용가능현금을 구분한 읽기전용 지도를 추가했습니다. 전업버튼은 기존대로 미납 차감 전 총자산 하한을 봅니다. 하한과 알바경로 비대칭·임의경제값을 바꾸지 않았으며 현실 생계가능성 판정이 아닙니다.

이 기능의 정상UI 검사는 별도 전체 개발본에서 수행하며 역사자료 제외로 공개 저장소에서 재현할 수 없습니다. 공개 npm test는 여전히 자산복기 합성30개만입니다.

## 진행 중 선택 복기

대시보드에서 이번 회귀의 실제 선택을 진행 중에도 확인하고, 사용자가 고른 지난 회귀 한 건과 같은 달끼리 나란히 펼쳐 볼 수 있습니다. 나란히 보기는 현재 게임 월까지로 제한하며 지난 회귀의 뒤쪽 선택은 그 표에서 제외합니다. 기존 전체 연표는 별도로 남습니다. 자동 전역일정 확인과 실제 입대 선택, 가상청구 납부·보류와 매매신청을 구분합니다. 선택이 없는 칸은 행동이 없었다는 증거가 아니며 선택월 미기록은 소급 보완하지 않습니다. 기록 선택과 펼침은 읽기 전용이며 새로고침하면 비교 선택은 초기화합니다.

같은 달이어도 생년·진로·경제모형 조건이 다를 수 있고, 구기록의 생년은 보존하지 않았습니다. 인과효과·수익률·추천이나 현실 진로우열을 계산하지 않습니다. 정상UI 확인은 비공개 전체 개발본에서만 가능하며 공개본에는 필요한 역사 데이터가 없습니다. 공개 npm test의 검사 범위는 바뀌지 않습니다.

## 별도 고1 달력 시작 시험

`school-calendar.js`는 통상진급의 초등·중등·고등 학년을 계산합니다. 옛3월 취학기준은2002년1\~2월생까지 적용하고2009학년도 취학 전환을 구분합니다.1975년1\~2월생 고1은1990-03,3\~12월생은1991-03이며 개인의 유예·조기입학·월반·실제 개학일은 확정하지 않습니다. 근거는1981시행 교육법 제95·96·102·106·151조와2008정부 취학변경 발표입니다.

개발본에서 기본 진입 링크의 `?start=school-calendar-trial`로 별도 동의 후1975\~2010년생 달력 시작을 시험합니다. 기존 기본/현금 모형 네 키와 다른 두 키를 쓰며 자동 이전하지 않습니다. 고1 선택과 이후 진학·복무를 월단위로 진행하고,1996-03전 자료공백은 실제 평온으로 표현하지 않으며 매매를 막습니다. 이후 구간도 기존 희소·일부 미검증자료 시연입니다. 시작100만원·순저축·입대시점/26개월·재학기간은 임의 시험가정이고 실제 해당연도 생활경제·복무규정이 아닙니다. 현금사건 모형과 이 시작시험은 연결하지 않았으며,1996고정 자산분해도 이 모형에는 계산하지 않습니다. 기본 시제품의1996-03시작은 그대로입니다.

이 공개본은 data/와 이미지를 제외해 이 시험 역시 실행할 수 없습니다. 공개 테스트30개는 기존 자산분해 합성검사일 뿐 고1 시작의 정상플레이 검사는 아닙니다. 별도 개발본에서 네 정상UI 경로를 실행해 시작·선택·월진행·2026-10결산·기록·기존 네 키 불변을 확인했습니다. 전체 역사 고증·자료권리·재미·현실 진로균형 검증을 뜻하지 않습니다.

## 고1 시험의 초기 선택뉴스8건

개발본 고1별도모드만1990\~1996년 선택뉴스8건을 별도 JSON에서 연결합니다. 기본/현금모형은 해당 자료를 요청하지 않으며 기존뉴스210건은 그대로입니다. 연구가격은 새 시장지수 관측1행으로313에서314점이 됐으나 기본/현금의3월 시작 선택가격은 바뀌지 않습니다. 상품 접근·미성년 가입·실제 펀드기준가·자료권리는 미확인이고1996-03전 매매차단과가격미표시를 유지합니다.
