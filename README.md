# 리턴: 회귀 투자자

2026-11-13 정적 웹 개발판. 고등학교로 회귀해 공부·알바, 진학, 취업·전업 투자와 자산 배분을 선택하는 비주얼 노벨형 투자게임 시제품입니다. 완성판·투자 조언·역사적 거래 재현이 아닙니다.

## 실행과 빌드

현재 실행 입구는 루트 `index.html`입니다. `cp 8-package-lock.json package-lock.json && npm ci && npm run build`로 `22-main.jsx`와 `11-App.jsx`, `20-game-bundle.js` 및 모듈들을 빌드합니다. `npm run serve` 후 로컬 서버 주소를 열어 실행하세요. HTML 파일을 직접 더블클릭하면 자료 fetch와 저장이 동작하지 않을 수 있습니다. React 19.1.0, React DOM 19.1.0, esbuild 0.25.5를 고정했습니다. 실행할 때 외부 CDN은 사용하지 않습니다.

`3-game-data.json.gz`에는 현재 자료와 과거 저장용 보존 자료66개를 경로→원문문자열 형태로 담았습니다. 브라우저의 DecompressionStream으로 엽니다. Node.js에서는 `JSON.parse(gunzipSync(readFileSync('3-game-data.json.gz')).toString())`로 내용을 확인할 수 있습니다. 로딩 실패 시 빈 자료로 대체하지 않고 중단합니다. 구 체크포인트 파일인 `engine.js`와 `data/`의 일부 자료, 기존 합성검사는 참고 보존본이며 최신 실행 입구와 다릅니다.

`45-build-pages.mjs`가 실제 파일명 대응표를 사용합니다. 번호 접두어도 파일명의 일부입니다. 현재 배포 파일은 `1-game.js`, `5-game.css`, `3-game-data.json.gz`이며, `4-game.js`, `44-game.js`, `9-build.mjs`, `10-pages.html`은 첫 업로드의 미연결 중간 산출물입니다. 현재 입구에서 쓰지 않습니다.

## 저장

저장은 현재 브라우저·사이트 주소의 localStorage에만 남습니다. 계정 동기화나 다른 주소의 자동 이전은 없습니다. 기존 자료 세대별 선택은 보존하며, 확인되지 않는 저장을 자동 변환하지 않습니다. 빌드가 바뀌어 실행함수 지문이 달라지면 이전 기록 문맥을 남기고 새 문맥을 추가할 수 있습니다. 브라우저 데이터 삭제·비공개 모드·저장 차단에 주의하세요. 실제 휴대폰 장기 보존은 미검증입니다.

## 데이터와 게임 가정

실제 확보된 가격 지점, 직접 작성한 사건요약과 명시한 게임설계값을 혼합합니다. sparse 가격 공백을 실제 시장 부재로 해석하지 않습니다. SPY/FXI는 미국 상장 ETF이며 FXI는 중국 본토 지수가 아닙니다. 주택은 서울·경기 대표 한 채의 추정 게임가격입니다. 생활비·수입·학비·거래비용·카오스 및 집중도는 설계값입니다. 개별 계약·가입자격·과거 최초 공표일·체결가를 보장하지 않습니다.

[데이터 안내](7-DATA-NOTICE.md)를 읽어 주세요. 공개 배포에 대한 개발자의 위험 수용은 자료 공급자의 이용 허락이 아닙니다. 출처 URL과 판단일/가용일은 자료 행과 게임 안 근거에서 확인할 수 있습니다. 외부 가격·뉴스·통계에 미술의 MIT를 적용하지 않습니다.

## 공통 미술

루트의 번호 접두어가 있는 `*-common.png`14개는 배경7종·주인공4종·소품3종의 허구 생성 미술입니다. 시대·장소·복장 고증이나 실제 인물 묘사가 아닙니다. [미술 허가 범위](14-asset-license.txt)를 참고하세요. 기존 `assets/`의 구 미술은 보존했지만 이번 실행은 루트의 공통 미술을 사용합니다.

## 검증 범위와 남은 일

정상 UI에서 만든 네 세대 저장을 같은6회 선택으로 이어가며 기존 공개 개발본과 새 정적 실행본을 비교했습니다. 이전 실행함수 문맥을 유지한 채 새 빌드 문맥이 추가되는 차이를 제외한 게임 상태는 일치했습니다. 새 시작 저장·재로드도 별도로 확인했습니다. 이는 합성 저장을 실제 휴대폰에서 장기 사용했다는 뜻이 아니며, 전체 조합·밸런스·재미·최종 미감을 보장하지 않습니다. 상세 상품 설명과 연출, 모바일 가독성은 계속 개선 중입니다. 대출·담보 확대는 본편에 포함하지 않습니다.

모바일 자료/미술 설명은 접어 두되 펼치면 기존 내용을 읽을 수 있습니다. 저장 범위 안내는 항상 보입니다. 이 화면 정리는 경제·주문·저장 형식을 바꾸지 않습니다.

첫 진학 경로 다음의 학업 방침은 별도 선택임을 화면에서 구분합니다. `1-choice-guide.js`는 현재 학업 설명의 표시만 정리하는 DOM 안내입니다. 계산 원문은 접기/펼치기로 보존하며 저장이나 게임 상태를 읽거나 쓰지 않습니다. 규칙·결과·버튼은 기존 게임 엔진 그대로입니다.


## 저장 사본 가져오기

게임 위쪽의 "저장 사본 가져오기 · 원래 공간 선택" 링크에서 JSON 사본을 선택합니다. 검사는 저장을 바꾸지 않습니다. 진행월과 완료 회귀 수를 확인한 뒤 적용하면 원래 저장을 덮어쓰지 않고 별도 공간을 선택합니다. "원래 저장 공간 선택"으로 돌아갈 수 있고, 가져온 공간도 지우지 않습니다. 두 공간은 합쳐지지 않으며 자동 동기화도 없습니다. 원본 JSON 파일은 따로 보관하세요.

안전 잠금을 지원하는 브라우저에서는 게임 탭 하나만 실행하며, 다른 게임 탭이 열려 있으면 가져오기 적용·공간 전환을 막습니다. 게임 탭을 닫은 뒤 다시 확인하세요. 안전 잠금 미지원 브라우저는 원래 저장 공간의 기존 게임을 유지하고 가져오기·공간 전환만 비활성화합니다. 가져온 공간이 이미 선택된 상태에서 잠금을 못 쓰면 저장을 바꾸지 않고 멈춥니다.

제한: 현재 진행이 없는 완료 기록 전용 사본, 알 수 없는 자료 묶음, 식별 없는 진행, 이전 완료 상세를 자동 요약하거나 완료 원문을 다시 작성해야 하는 사본은 가져오지 않습니다. 검사 통과는 모든 이후 플레이나 편집한 파일의 사실성을 보장하지 않습니다. 파일은 외부로 보내지 않고 메모리로 격리된 게임 시작·대시보드 검사와 원문 대조를 거칩니다.

`npm run build`는 기존 실행본과 함께 `import-review.js`, `import-validator.js`를 생성합니다. `import.html`과 관련 소스도 같은 경로에 배포해야 합니다. `46-build-import.mjs`는 원래 엔진 소스를 바꾸지 않고 검사 전용 빌드를 만듭니다. 검증 후 실제 게임으로 계속 진행할 때는 원래 엔진을 사용합니다.

원룸과 전업 서재는 2000년 이전 / 2000~2009년 / 2010년 이후의 허구 미술 6종을 추가로 사용합니다. 미술상 구분이며 실제 역사·장비 구입·자산·주택의 모습이나 보급 시점을 뜻하지 않습니다. 기존 공통 배경은 보존하며 새 이미지 로드 실패 시 공통 배경을 사용합니다. 게임 규칙·경제·자료는 그대로입니다.
