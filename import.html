저장 사본 검사

원래 진행은 그대로 두고, 선택한 JSON 사본의 형식·자료 묶음과 게임 시작 검사를 확인합니다.

검사만으로는 저장을 바꾸지 않습니다. 적용은 검사 후 별도로 확인합니다. 원래 진행은 보존하며, 정상 검사 결과도 이후 플레이 전체를 보장하지 않습니다.

1. 사본 선택

파일에는 게임 선택·자산 기록이 들어 있습니다. 선택한 사본은 이 화면 안에서만 검사하며 외부로 보내지 않습니다.

파일을 선택해 주세요.

2. 별도 공간에 가져오기

원래 진행과 완료 회귀는 덮어쓰지 않습니다. 가져온 공간은 원래 공간과 합쳐지지 않습니다. 원본 JSON 파일을 계속 보관해 주세요.

다른 탭의 게임은 먼저 닫아 주세요. 돌아가도 가져온 공간은 지우지 않습니다. 이 버튼은 처음 사용하던 이 주소의 저장을 선택합니다.
